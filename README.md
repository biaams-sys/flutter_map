#  App Caminhadas

Aplicativo mobile desenvolvido em **Flutter** para rastreamento de caminhadas, cálculo de rotas em tempo real, contagem estimada de calorias e distância, e registro de fotografias do percurso com armazenamento local.

##  Tecnologias Utilizadas

* [Flutter](https://flutter.dev/) - Framework UI multiplataforma
* [Dart](https://dart.dev/) - Linguagem de programação
* [Provider](https://pub.dev/packages/provider) - Gerenciamento de estado
* [Hive](https://pub.dev/packages/hive) & [Hive Flutter](https://pub.dev/packages/hive_flutter) - Banco de dados NoSQL local rápido
* [Flutter Map](https://pub.dev/packages/flutter_map) & [latlong2](https://pub.dev/packages/latlong2) - Exibição de mapas e renderização de rotas com OpenStreetMap
* [Geolocator](https://pub.dev/packages/geolocator) - Obtenção da localização do dispositivo via GPS
* [HTTP](https://pub.dev/packages/http) - Requisições para a API pública de rotas OSRM
* [Image Picker](https://pub.dev/packages/image_picker) - Captura de fotos via câmera do dispositivo

##  Instruções para Execução

### Pré-requisitos
* Flutter SDK instalado (versão 3.x ou superior)
* Android Studio ou VS Code configurado com extensão Flutter
* Emulador Android ou dispositivo físico com depuração USB ativada

### Passos para rodar o projeto

1. **Clonar o repositório:**
   ```bash
   git clone [https://github.com/biaams-sys/flutter_map.git](https://github.com/biaams-sys/flutter_map.git)
   cd flutter_map

```

2. **Instalar as dependências:**
```bash
flutter pub get

```


3. **Executar a aplicação:**
```bash
flutter run

```
